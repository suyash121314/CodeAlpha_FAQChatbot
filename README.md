This project is part of the CodeAlpha AI Internship.

Description

This is a Smart FAQ Chatbot developed using Python and Streamlit. It uses Natural Language Processing (NLP) techniques to understand user queries and provide relevant answers from a predefined dataset.

Features

* Answers user questions based on FAQ data
* Uses NLP similarity (TF-IDF & cosine similarity)
* Simple and interactive chat interface
* Displays confidence score

Technologies Used

* Python
* Streamlit
* Pandas
* Scikit-learn
